# Tony Router Design

The approved control-plane UI is governed by [`docs/ui-design-contract.md`](docs/ui-design-contract.md).

That document is the project-specific visual contract and overrides generic design examples. Implementation must preserve the approved layout, information hierarchy, navigation model, density, typography, spacing, surfaces, table structure, responsive priorities, and interaction intent.

The approved mockup is identified in the contract by filename and SHA-256. Substantial deviations require explicit approval and a new visual review.
